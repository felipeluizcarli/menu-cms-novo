
# Menu CMS

Sistema de gerenciamento de restaurante desenvolvido com React e TypeScript.

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Axios
- TanStack Query
- React Router

## Instalação

```bash
npm install
```

## Executar o projeto

```bash
npm run dev
```

## Funcionalidades previstas

- Gerenciamento de categorias
- Gerenciamento de produtos
- Gerenciamento de mesas
- Visualização de comandas
- Gerenciamento do status dos pedidos

## Observações

O projeto utiliza uma API NestJS para consultar e atualizar os dados do restaurante.
